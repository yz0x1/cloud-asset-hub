## A. 已对齐原版（可认为完成）

- 三 Tab：云存储 / 云服务 / 其他工具

### 云存储
- 九家厂商入口：七牛 / 腾讯 / 青云 / 阿里 / 又拍 / AWS / 京东 / 金山 / MinIO
- 双栏浏览器、网格/列表、面包屑、搜索、拖拽上传
- 上传/多选/文件夹、下载、删除、建目录、重命名/移动、预览、导出 URL、同步、右键菜单
- **青云 / 又拍：mkdir + move 已接入主浏览器**
- **又拍已并入主浏览器**（不再孤立表单）
- 空间选项开关、上传记录、CDN（七牛）

### 云服务
- 五家 AK：阿里 / 腾讯 / 华为 / UCloud / AWS

- 华为 / AWS / UCloud：接管与列表类能力（深度浅于阿里）

### 其他工具
